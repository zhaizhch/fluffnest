# 绒窝 FluffNest · 方案 v1（与代码对齐）

> **品牌名**：绒窝 / FluffNest  
> **仓库名**：`macos-deskpet`（工程目录可保持不变）  
> **Slogan**：桌边有个软软的小窝  
> **版本**：`0.2.1`（`package.json` / `tauri.conf.json`）  
> **定位**：常驻 macOS 的萌系桌面宠物——**多只独立宠物**养成与图鉴收集，温和提醒，可自主玩耍；「绒窝小铺」用金币解锁宠物（实付预留）。

---

## 0. 已确认决策

| # | 议题 | 结论 |
|---|------|------|
| 1 | 技术栈 | **Tauri 2 + React + TypeScript + Rust**；桌宠渲染为 **Canvas 2D 播放 Codex 精灵图集**（组件名 `PixiPet`，非 Pixi 运行时） |
| 2 | 美术 / 收集 | **每只宠物独立命名 + 独立图集**；**不做**同宠多皮肤换装、**不做** egg→adult 成长阶段 |
| 3 | 会议提醒 | **v1 仅手动日程**；日历接入后续版本 |
| 4 | 商业化 | 「绒窝小铺」卖 **宠物解锁**（`pet_unlock`）；`coin` 兑换；`real` / IAP 字段预留 |
| 5 | 品牌 | **绒窝 FluffNest** · Bundle ID `com.fluffnest.deskpet` |
| 6 | 持久化 | 本地 **`state.json`**（非 SQLite） |

### 相对早期草案的变更

| 早期草案 | 当前实现 |
|----------|----------|
| 4 宠（糯糯/朵朵/豆豆/墨墨）× 多套皮肤 | **多只**独立宠物（含大量人型），图鉴按分类平铺切换 |
| `stage` 成长 + `skinId` 换装 | 字段仅作旧存档兼容，运行时忽略 |
| 小铺卖皮肤 / 配饰 | 小铺卖 **解锁宠物** |
| SQLite | `~/Library/Application Support/com.fluffnest.deskpet/state.json` |
| 主题目录 `themes/<speciesId>/` | `public/pets/<pack>/spritesheet.webp` + `pet.json` |

遗留代码（`SoftPet` / `evolution.ts` / `skinLines.ts` 等）仍保留在仓库中，**主路径未引用**。

## 2. 用户体验概览

### 2.1 日常循环

```
启动 → 当前出战宠出现在桌面 → 自主玩耍
         ↓
   主人点击互动 → mood / energy / bond 变化 + 气泡
         ↓
   到点提醒（喝水 / 久坐 / 手动会议）→ 动画 + 系统通知
         ↓
   小铺金币解锁 / 每日登录礼 → 图鉴更新 → 切换出战
```

### 2.2 交互方式

| 操作 | 效果 |
|------|------|
| 左键点击 | 互动动画（轻拍等）+ 气泡 |
| 拖拽 | 移动宠物窗；松手后继续自主行为 |
| 双击 / 右键 | 打开绒窝面板 |
| 托盘 | 显示/隐藏宠物、打开面板、退出；左键托盘也可开面板 |
| 面板 · 状态 | 属性条 + 互动按钮 + 已解锁宠快速切换 |
| 面板 · 图鉴 | 全部宠物卡片；已解锁可切换出战 |
| 面板 · 提醒 | 规则列表 + 添加手动会议 |
| 面板 · 小铺 | coin 解锁宠物；`real` 显示「即将开放」 |
| 面板 · 设置 | 静音 / 专注 / 置顶 |

### 2.3 自主行为（轻量状态机）

实现见 `src/pet/behaviorEngine.ts` + `PetApp.tsx`。

典型行为：`idle` / `walk` / `sleep` / `stretch` / `wave` / `play` / 互动类（`pat` `feed` `hug` …）/ `react`（提醒）等。

- 闲时按性格挑选动作序列并偶发平移窗口
- **专注模式**：减少自主移动，仍可强提醒
- 精灵动画：Codex 图集行映射（idle / run / wave / jump …），见 `src/lib/codexAtlas.ts`

## 3. 核心系统设计

### 3.1 宠物模型：一只一宠

**原则**：图鉴里每一项都是独立宠物（独立 `id` / `name` / 精灵图集），切换即换人，不是「同一角色换装」或「同一角色长大」。

目录定义：`src/lib/petCatalog.ts`（含 `category`）与 `src-tauri/src/state.rs` 的 `catalog()`（后端种子，需保持同步）。当前约 **61** 只（人型伙伴约 26 只）。

#### 分组（图鉴 / 小铺按此分类展示）

| ID | 名称 | 说明 |
|----|------|------|
| `fluff` | 毛绒小窝 | 软软动物系 |
| `companion` | 人型伙伴 | 桌边人型 / 法师魔女 |
| `idol` | 偶像舞台 | 歌姬与偶像 |
| `digi` | 数码伙伴 | 数码兽风 |
| `fantasy` | 奇幻旅人 | 狐灵与旅法 |
| `star` | 星光卡卡 | 卡卡系列 |

#### 解锁方式

| `unlock` | 含义 |
|----------|------|
| `default` | 开局已解锁（如糯糯、咪可、子平波波、珍珠偶像、露娜、滚球兽、亚古兽、银月狐、卡卡） |
| `shop` | 绒窝小铺用 `coin` 购买 `pet_unlock` |
| `login` | 每日登录连续天数礼包解锁（如芝芝、粉珍珠、Ｖ仔兽、小狗帽、小芙莉莲） |

稀有度：`N` / `R` / `SR` / `SSR`（展示与小铺标价用）。

资源：`public/pets/<pack>/spritesheet.webp`（+ 可选 `pet.json`）；`PetDef.sprite` 指向图集路径。

### 3.2 养成系统

| 属性 | 范围 | 规则（示意） |
|------|------|----------------|
| mood | 0–100 | 互动↑；空闲 tick 可缓慢变化 |
| energy | 0–100 | 玩耍↓；休息/喂食↑ |
| bond | 0–∞ | 互动与提醒打卡累积 |
| personality | `calm` / `lively` / `clingy` | 影响自主行为与文案倾向 |
| unlocked | bool | 是否可出战切换 |
| isActive | bool | 当前桌面展示的那一只 |

同一时间桌面展示 **1 只**；面板图鉴切换有短过渡（行为 `switch`）。

### 3.3 「绒窝小铺」

商品类型以 **`pet_unlock`** 为主；`real` 商品 `available: false`，文案「即将开放」。

```ts
type ShopProduct = {
  id: string
  sku: string                 // 如 pet.axo.unlock
  type: string                // 实际为 "pet_unlock"
  targetId: string            // speciesId
  currency: "coin" | "gem" | "real"
  amount: number
  rarity: string
  available: boolean
  name: string
  iapProductId?: string | null
}
```

- 钱包：`coin`（养成 / 打卡 / 登录）、`gem`（预留）
- 管理员模式（`settings.isAdmin`）：开发期可一键满解锁（见 Rust `grant_admin_unlocks`）

### 3.4 提醒系统

| 类型 | 触发 | 表现 |
|------|------|------|
| water | 默认每 60 分钟 | 宠物 `react` + 系统通知 |
| stretch | 默认每 45 分钟 | 同上 |
| meeting | 手动添加 `at`（ISO） | 到点触发 |
| custom | 可扩展 | 通用 |

- 后端每 **30s** 轮询（`lib.rs`）
- 支持启用开关、删除、打卡（`complete_reminder` → 金币等）
- 设置项含静音（影响通知体验）

### 3.5 每日登录

`DailyLogin`：连续天数 `streak`、是否已领 `claimedToday`、`pendingRewards`。

按 streak 循环发奖励（金币或指定 `pet` 解锁），逻辑在 `state.rs` 的 `reward_for_streak`。

## 6. 数据模型（与代码对齐）

```ts
type PetDef = {
  id: string                    // speciesId，如 "mochi"
  name: string
  personality: "calm" | "lively" | "clingy"
  sprite: string                // "/pets/.../spritesheet.webp"
  spriteVersion?: number
  vibe: string
  unlock: "default" | "shop" | "login"
  rarity: "N" | "R" | "SR" | "SSR"
  shopPrice?: number
}

type PetInstance = {
  id: string                    // 如 "pet-mochi"
  speciesId: string
  name: string
  mood: number
  energy: number
  bond: number
  personality: string
  isActive: boolean
  unlocked: boolean
  lastInteractAt: string
  // 旧存档兼容，运行时不使用：
  skinId?: string
  stage?: string
  hatchedAt?: string
}

type ReminderRule = {
  id: string
  type: string                  // water | stretch | meeting | …
  title?: string | null
  intervalMinutes?: number | null
  at?: string | null
  enabled: boolean
  snoozeMinutes: number
  lastFiredAt?: string | null
}

type Wallet = { coin: number; gem: number }

type DailyLogin = {
  lastClaimDate?: string | null
  streak: number
  totalDays: number
  pendingRewards: DailyReward[]
  claimedToday: boolean
}

type Settings = {
  muted: boolean
  focusMode: boolean
  alwaysOnTop: boolean
  isAdmin?: boolean
}

type AppState = {
  pets: PetInstance[]
  reminders: ReminderRule[]
  wallet: Wallet
  ownedActions: { actionId: string; obtainedAt: string }[]
  dailyLogin: DailyLogin
  settings: Settings
  shopCatalog: ShopProduct[]
}
```

主要命令（`src/lib/api.ts`）：`get_state` · `get_active_pet` · `interact` · `switch_pet` · `update_settings` · `upsert_reminder` · `add_meeting_reminder` · `delete_reminder` · `complete_reminder` · `purchase_product` · `claim_daily_login` · `tick_idle` · `get_owned_actions`。

## 9. 风险与对策

| 风险 | 对策 |
|------|------|
| 宠物与图集数量大 | 按 pack 静态资源；切换时再加载图集 |
| 常驻 CPU | Canvas 帧循环按行为控速；隐藏窗时降频（可继续优化） |
| 提醒打扰 | 默认可关规则 + 专注模式 + 静音 |
| 小铺过早承诺付费 | 仅 coin；`real` 标「即将开放」 |
| 前后端目录双份 | 改宠时同步 `petCatalog.ts` 与 `state.rs`；后续考虑生成 |
| 透明窗多屏 | 发布前多屏回归 |
