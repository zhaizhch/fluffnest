# 绒窝 · 用户安装指南

适用于从 **GitHub Releases** 下载安装包的所有用户。

---

## 1. 系统要求

- macOS **12.0** 及以上
- Apple Silicon（M 系列）或 Intel 芯片

---

## 2. 下载

1. 打开仓库的 [Releases](https://github.com/zhaizhch/fluffnest/releases/latest) 页面  
2. 在最新版本 **Assets** 中下载对应安装包：

| 你的 Mac | 下载文件 |
|----------|----------|
| Apple Silicon（M1/M2/M3/M4…） | `FluffNest_x.y.z_aarch64.dmg` |
| Intel | `FluffNest_x.y.z_x86_64.dmg` |

不确定芯片类型时，打开「终端」执行：

```bash
uname -m
```

- 输出 `arm64` → 选 **aarch64**
- 输出 `x86_64` → 选 **x86_64**

也可下载同名的 `.zip`（解压得到 `FluffNest.app`）。

---

## 3. 安装

### 方式 A：DMG（推荐）

1. 双击打开下载的 `.dmg`
2. 将 **FluffNest** 拖到左侧 **应用程序（Applications）** 文件夹
3. 弹出 DMG 窗口可关闭；安装包可删

### 方式 B：ZIP

1. 双击解压 `.zip`
2. 将得到的 `FluffNest.app` 拖到「应用程序」

---

## 4. 首次打开（重要）

未经过 Apple 公证的安装包，系统可能提示「无法验证开发者」或「已损坏」。

任选其一：

### 方法 1：右键打开

1. 打开「应用程序」
2. **按住 Control 键点击**（或右键）`FluffNest` / `绒窝`
3. 选 **打开** → 再点 **打开**

### 方法 2：清除隔离属性

```bash
xattr -cr /Applications/FluffNest.app
```

然后从启动台或「应用程序」正常打开。

---

## 5. 使用

| 操作 | 效果 |
|------|------|
| 拖拽桌面宠物 | 移动位置 |
| 单击 | 抚摸互动 |
| 双击 / 右键 | 打开绒窝面板 |
| 菜单栏托盘图标 | 显示/隐藏、面板、退出 |

数据保存在：

```
~/Library/Application Support/com.fluffnest.deskpet/state.json
```

---

## 6. 校验下载是否完整（可选）

发布页提供 `SHA256SUMS.txt`：

```bash
cd ~/Downloads
shasum -a 256 -c SHA256SUMS.txt
```

对应文件显示 `OK` 即可。

---

## 7. 卸载

1. 退出绒窝（托盘 → 退出）
2. 将「应用程序」里的 FluffNest 移到废纸篓
3. （可选）删除数据：  
   `~/Library/Application Support/com.fluffnest.deskpet/`

---

## 8. 常见问题

**Q: 拖进应用程序后闪退？**  
先执行 `xattr -cr /Applications/FluffNest.app` 再打开。仍不行请到 Issues 反馈 macOS 版本与芯片类型。

**Q: 下载了错误架构会怎样？**  
可能无法启动。按第 2 节重新下载对应包即可。

**Q: 以后如何升级？**  
到 Releases 下载更新的 DMG，覆盖拖入「应用程序」即可（一般保留养成数据）。
